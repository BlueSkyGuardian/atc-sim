AI lab

A language model controls the simulation headlessly: it reads the situation, gives instructions (synthetic pilots fly them), and each run is evaluated and kept as labelled experience data for training. Every run can be replayed 1:1 in the debrief.

Runs

Where the model answers. RunPod serverless: a vLLM worker endpoint (its OpenAI-compatible route https://api.runpod.ai/v2/<endpoint id>/openai/v1, your RunPod API key). OpenAI-compatible: any server with /v1/chat/completions — a RunPod pod running vLLM, TGI or Ollama (https://<pod id>-8000.proxy.runpod.net/v1), or another provider. The built-in baseline is a scripted controller: a reference score, and experience data without a model. API keys are stored encrypted and never shown again.
